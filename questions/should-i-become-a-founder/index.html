Show notes ↗

Will's blunt advice: "I recommend that you don't be a founder" — because "it's so hard and there's a lot of luck involved." The exception: if you feel "so strongly, so passionately that I have to do this," then "you have no choice, you better go do it."

More from this episode

Will says to anyone considering it, he recommends you don't, because it's so hard, there's a lot of luck, and even if it works out "it's a very long journey" with "really no easy route." If you only "might wanna start a company," then "your company's probably not gonna work." But if you feel you "need to be a founder" so strongly and passionately that you have to, "then you better be prepared to put in a lot of work." He also says to "know the game that you're playing in" — the venture capital game means going "super hard" and "super big" in a "very risky, volatile, crazy kind of space."
